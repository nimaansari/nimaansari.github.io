01 — Desktop app · Python · NPU enginesBeta v0.3

OpenNPU

Local AI on the NPU of AMD Ryzen AI laptops, on Linux.

macOS has Core ML. Windows has Copilot+ PCs. On Linux, the NPU in millions of Ryzen AI laptops sits idle. OpenNPU runs your own models on it with its own NPU engines and no closed runtime underneath. It does chat, vision and voice (Whisper on the NPU), and exposes an OpenAI- and Ollama-compatible API, so tools like Open WebUI and Continue can use the NPU as their backend.

02 — Kernels · IRON / mlir-aieBenchmarked

Laya on NPU

A 421M-parameter decision model, with all 112 encoder GEMMs on the NPU.

I compiled open IRON/mlir-aie kernels locally with Peano and wrote one engine that packs every matrix shape into a single xclbin. Switching between per-shape binaries cost 2.7 ms per GEMM in re-partitioning, which was the whole bottleneck. With the single binary, the NPU beats the best CPU path and returns the same decisions on every test.

03 — Benchmark · RAPL power telemetryResearch

npu-bench

Tokens per second per watt: NPU vs iGPU vs CPU, on the same laptop.

Peak throughput isn't the interesting number for always-on assistants. Energy per token is. This harness streams the same prompts through FastFlowLM (NPU), LM Studio on Vulkan (iGPU) and Ollama (CPU), samples package power every 200 ms, and lists its own caveats. A priority-queue daemon on top shares the NPU between agents.

LLM Cost Watchdog

Cost monitoring for AI agents, built so an agent loop can't run up $2,400 overnight.

It tracks spend live across providers, enforces budget ceilings, and uses AST analysis to catch runaway loops in code before they run. Before you pick a model, it estimates what the job will cost and suggests cheaper models that would do it.
